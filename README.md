Cryptocurrency Dashboard
Project Overview
The Cryptocurrency Dashboard is a Power BI project designed to present cryptocurrency-related data in an interactive and easy-to-understand visual format. The dashboard helps users explore available crypto data, compare values, and identify patterns or trends using charts and other visual elements.
Project File
CryptoCurrency_Dashboard.pbix --- Power BI Desktop report file.
Objectives
Present cryptocurrency data in a clear visual format.
Make it easier to compare cryptocurrency metrics.
Explore trends and patterns in the data.
Support quick, data-driven understanding through interactive visuals.
Tools Used
Microsoft Power BI Desktop --- for data visualization and dashboard development.
Cryptocurrency dataset --- the source data used by the report (dataset details can be added here).
Dashboard Features
Interactive report visuals and charts.
